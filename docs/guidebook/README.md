# Guidebook PFG Portal

[← Halaman utama](../../README.md)

Panduan ini menjelaskan cara memakai PFG Portal langkah demi langkah, untuk **admin**, **guru (teacher)**, dan **siswa (student)**. Tidak perlu pengetahuan pemrograman untuk mengikutinya.

## Mulai dari Mana?

| Saya ingin… | Buka |
|-------------|------|
| Memahami istilah di aplikasi dan hak tiap peran | [Istilah & Hak Akses](01-istilah-dan-hak-akses.md) |
| Mendaftar, masuk, atau mengenal menu | [Memulai & Mengenal Tampilan](02-memulai.md) |
| Mengoperasikan aplikasi sebagai **admin** | [Panduan Admin](03-panduan-admin.md) |
| Mengoperasikan aplikasi sebagai **guru** | [Panduan Guru](04-panduan-guru.md) |
| Mengoperasikan aplikasi sebagai **siswa** | [Panduan Siswa](05-panduan-siswa.md) |
| Mengubah profil atau kata sandi | [Mengelola Profil](06-profil.md) |
| Melihat urutan proses dari offering sampai kelas berjalan | [Ringkasan Alur](07-ringkasan-alur.md) |
| Mengerti arti pesan error yang muncul | [Pesan & Solusi](08-pesan-dan-solusi.md) |
| Mengetahui fitur yang belum selesai | [Fitur Dalam Pengembangan](09-fitur-dalam-pengembangan.md) |

## Daftar Isi

1. [Istilah & Hak Akses](01-istilah-dan-hak-akses.md) — istilah penting, tahapan kelas, tabel hak akses per peran
2. [Memulai & Mengenal Tampilan](02-memulai.md) — daftar akun, masuk, lupa kata sandi, keluar, menu samping, notifikasi
3. [Panduan Admin](03-panduan-admin.md) — Settings, class offering, approve/reject guru, tambah kelas, Set Time, ubah/hapus kelas
4. [Panduan Guru](04-panduan-guru.md) — melamar offering, status lamaran, lesson plan, detail kelas
5. [Panduan Siswa](05-panduan-siswa.md) — dashboard dan menu siswa
6. [Mengelola Profil](06-profil.md) — data pribadi, kata sandi, hapus akun
7. [Ringkasan Alur](07-ringkasan-alur.md) — langkah lintas peran beserta syaratnya
8. [Pesan & Solusi](08-pesan-dan-solusi.md) — arti pesan yang sering muncul
9. [Fitur Dalam Pengembangan](09-fitur-dalam-pengembangan.md) — fitur yang datanya masih contoh

## Cara Membaca Panduan

Setiap halaman memakai penanda berikut:

> **Prasyarat** — kondisi yang harus terpenuhi sebelum langkah bisa dilakukan.

> **Catatan** — informasi tambahan atau batasan yang perlu diketahui.

> 📘 **Detail teknis** — tautan ke [dokumentasi teknis](../teknis/) yang membahas bagian tersebut. Boleh dilewati jika Anda hanya mengoperasikan aplikasi.

Di bagian bawah setiap halaman terdapat tautan ke halaman sebelumnya dan berikutnya.
