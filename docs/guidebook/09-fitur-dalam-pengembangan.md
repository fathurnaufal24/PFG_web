# Fitur yang Masih Dalam Pengembangan

[Daftar isi Guidebook](README.md) · [Halaman utama](../../README.md)

Fitur yang sudah tampil tetapi datanya masih contoh atau belum bisa disimpan.

---

Fitur berikut sudah terlihat di aplikasi, tetapi **datanya masih contoh** atau belum bisa disimpan:

| Fitur | Kondisi saat ini |
|-------|------------------|
| Pendaftaran siswa ke kelas | Belum tersedia |
| Absensi, laporan siswa, riwayat sesi, parent meeting di detail kelas | Data contoh; perubahan tidak tersimpan |
| Perpindahan tahap Active → Report → Parent Meeting → Class Ended | Belum bisa dilakukan dari aplikasi |
| Menu **Revenue** (riwayat gaji) | Tampilan contoh |
| Menu **My Schedule / Jadwal Saya** | Kalender contoh |
| Menu **Module / Modul Belajar** | Tampilan contoh; tombol **Unlock** belum berfungsi |
| Menu **Parent Meeting** | Tampilan contoh; tombol **Create PM** belum berfungsi |
| Tabel *Pending Attendance* di dashboard guru | Data contoh |
| Masuk/daftar dengan Google atau Facebook | Belum berfungsi |
| Tautan menu di halaman depan (About, Testimoni, dll.) | Belum mengarah ke halaman mana pun |

> 📘 **Detail teknis:** [Catatan & masalah](../teknis/08-catatan-dan-masalah.md)
